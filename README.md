# Zahrah Wasif - Portfolio Website

A modern, responsive portfolio website built with React.js. This website showcases professional skills, projects, and contact information.

## Features

- ✨ Modern and attractive design
- 📱 Fully responsive (mobile, tablet, desktop)
- ⚡ Fast and optimized performance
- 🎨 Beautiful animations and transitions
- 🔗 Social media integration
- 📧 Contact form
- 🚀 Ready for Vercel deployment

## Technologies Used

- React.js
- CSS3 (Custom responsive styles)
- React Icons
- HTML5

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Zahrah-wasif1/porfilo.git
cd porfilo
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

The app will open at [http://localhost:3000](http://localhost:3000)

### Build for Production

```bash
npm run build
```

This creates an optimized production build in the `build` folder.

## Deployment on Vercel

This project is configured for easy deployment on Vercel:

1. Push your code to GitHub
2. Go to [Vercel](https://vercel.com)
3. Import your GitHub repository
4. Vercel will automatically detect the React app and deploy it
5. Your site will be live!

Alternatively, use Vercel CLI:

```bash
npm i -g vercel
vercel
```

## Customization

To customize this portfolio with your own information:

1. Update personal details in `src/components/Hero.js`
2. Modify skills in `src/components/Skills.js`
3. Update projects in `src/components/Projects.js`
4. Change contact information in `src/components/Contact.js`
5. Update social media links throughout the components
